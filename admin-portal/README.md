# Axisora Forge Academy - Admin Portal

Angular 17 standalone components admin web application.

## Setup
1. npm install
2. npm start (dev server at http://localhost:4200)
3. npm run build (production build)

## Modules
- Dashboard (stats, recent enrollments, upcoming events)
- Students (CRUD)
- Courses (CRUD)
- Faculty (CRUD)
- Placements (CRUD)
- Payments (transactions, revenue)
- Settings (institute profile, payment config)
